# 10.09 — Enter an unfamiliar topic and produce a checked first result

Build a small independent learning plan, use references and help selectively, and produce an initial artifact that can be checked against a clear standard.

This is beginner resourcefulness, not a claim of expertise or a reason to avoid appropriate instruction. Safe use of experts and documentation is part of independence.

Default unfamiliar topic: three-bit binary numbers. Supplied reference: the left, middle and right places are worth 4, 2 and 1; a 1 includes the place value and a 0 omits it. Thus 101 means 4 plus 1, or 5. Target artifact: a checked table for decimal 0 through 7. Use paper or a plain text editor.

Forty-five minutes for a first attempt and fifteen minutes for a correction or extension.

## 1. State the outcome and locate the minimum prerequisites

Write what the table must contain and identify the two prerequisites: place value and adding selected weights. Read the supplied reference, attempt 010 and 111, and mark what is unclear before seeking more material. Make a three-step plan: generate the table, verify every row, explain one unfamiliar row. Avoid gathering a long resource list instead of attempting the topic.

- The first artifact has a concrete completion standard
- Prerequisites are separated from advanced topics
- An initial attempt reveals an actual question
- The plan is short enough to execute now

## 2. Construct the artifact and ask a targeted question when stuck

Build rows from 000 through 111 and calculate each weighted sum. Check that the decimal values are exactly 0, 1, 2, 3, 4, 5, 6 and 7 with no duplicate or missing value. When an error appears, ask a precise question such as why does 011 equal 3 rather than 11. Use the reference or a willing knowledgeable person, then record the explanation that resolves that specific obstacle.

- A complete first table is produced
- Every row is checked rather than spot-approved
- A help request targets a specific obstacle
- The answer is used to correct the artifact

## 3. Explain the result and test a limited extension

Without copying the reference, explain 110 as 4 plus 2. Then predict how a fourth place with value 8 would represent 9, and verify 1001 by adding its included values. State what you now understand and what remains outside the exercise, such as signed values or computer encodings. Choose the next small learning question only after preserving the checked first result.

- The learner explains a row in their own words
- A new four-place example is attempted and checked
- Known and unlearned material are distinguished
- The next question follows demonstrated initial work

Use physical counters, large-print place values or audio explanation. An experienced learner may use the extension as the initial target and explain why 1111 is 15. Do not practice independent learning on hazardous or regulated tasks without required supervision.

Learning guide — unscored

Independence means directing help, not refusing it

Independent learning fixes a bounded outcome, identifies minimum prerequisites, attempts something checkable, asks a precise question when evidence exposes a gap, and uses the answer to revise the work. It is not collecting resources, guessing without a reference or avoiding appropriate experts. Record what was known, attempted, looked up, explained and still unknown. A correct first artifact supports one beginner result under these materials; it does not establish expertise in computing or a general trait of resourcefulness.

Supplied three-bit place-value reference

Read a three-bit row from left to right as places worth 4, 2 and 1. A 1 includes that place value; a 0 contributes zero. Add the included values to obtain the decimal value. Example: 101 includes 4 and 1, so it equals 5. Leading zeroes retain the three-place layout: 010 includes only 2. The target artifact contains every bit pattern from 000 through 111 exactly once, paired with decimal 0 through 7 exactly once. This card covers unsigned place value only—not signed numbers, storage, encoding or computer architecture.

Worked example on a different two-bit system

With two places worth 2 and 1, the complete patterns are 00 = 0, 01 = 1, 10 = 2 and 11 = 3. For 10, include 2 and omit 1. The check is structural: all four patterns appear, all four decimal values appear, and each row equals its selected weights. This demonstrates the method without supplying the requested three-bit table.

Ask only after the artifact identifies the obstacle

“Teach me binary” is too broad for this cycle. “Why does the left 1 in 101 contribute four?” names a specific place-value obstacle. Prefer the supplied reference first; consult a traceable source or willing knowledgeable person when it cannot resolve the question. Copying a finished table can hide the obstacle. Refusing a needed reference wastes effort. Independence is visible when the learner selects, evaluates and applies help while retaining the correction trail.

Change the representation while keeping place value visible

Use three labeled physical counters, large-print columns, tactile on/off markers, audio descriptions or a helper who records the learner’s selected weights. A calculator may check addition after the included places are identified. An experienced learner may start at four bits but must retain the same check trail. Hazardous, regulated, medical, legal or safety-critical topics require appropriate instruction and are not suitable for proving independence through trial and error.

Let the checked artifact choose the next question

If every three-bit row and the extension are explained correctly, choose one bounded next topic such as converting decimal 8–15 to four bits. If a weight-selection error remains, practice only that prerequisite on new rows. If addition caused the error, keep binary structure fixed and use an accessible arithmetic support. Record completed, partial, adverse or inconclusive; do not equate a resource list, effort or one correct guess with independent learning.
