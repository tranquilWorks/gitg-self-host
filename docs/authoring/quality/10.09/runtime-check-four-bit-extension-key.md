Learning guide — unscored

Supplied three-bit place-value reference

Read a three-bit row from left to right as places worth 4, 2 and 1. A 1 includes that place value; a 0 contributes zero. Add the included values to obtain the decimal value. Example: 101 includes 4 and 1, so it equals 5. Leading zeroes retain the three-place layout: 010 includes only 2. The target artifact contains every bit pattern from 000 through 111 exactly once, paired with decimal 0 through 7 exactly once. This card covers unsigned place value only—not signed numbers, storage, encoding or computer architecture.

Transfer the rule to one added place

A fourth place is added on the left with value 8, giving places 8, 4, 2 and 1. Without copying a table, calculate 1001, 1010 and 1111 by listing included values. Then explain one answer in your own words and name two topics this extension still does not cover. Preserve the attempt and any help before opening the key. If the three-bit table was not checked, return to it rather than presenting the extension as a substitute.

Check your attempt: Check the new place without extending the claim

1001 includes 8 and 1, so it equals 9. 1010 includes 8 and 2, so it equals 10. 1111 includes 8, 4, 2 and 1, so it equals 15. A correct explanation names the selected places and their sum. Signed values, text encodings, storage order, arithmetic circuits and software representation all remain outside this exercise. Correct extension rows support transfer of this place-value rule to one added place, not broad computing knowledge or expertise.
