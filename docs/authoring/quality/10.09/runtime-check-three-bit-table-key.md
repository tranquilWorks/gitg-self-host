Learning guide — unscored

Supplied three-bit place-value reference

Read a three-bit row from left to right as places worth 4, 2 and 1. A 1 includes that place value; a 0 contributes zero. Add the included values to obtain the decimal value. Example: 101 includes 4 and 1, so it equals 5. Leading zeroes retain the three-place layout: 010 includes only 2. The target artifact contains every bit pattern from 000 through 111 exactly once, paired with decimal 0 through 7 exactly once. This card covers unsigned place value only—not signed numbers, storage, encoding or computer architecture.

Build and audit the complete three-bit table

Before opening the key, write rows 000, 001, 010, 011, 100, 101, 110 and 111. For each row, show the included 4/2/1 weights and your decimal total. Audit that every pattern appears once, decimal values 0–7 appear once and each total matches its weights. Preserve the first error rather than silently replacing it. Explain why 011 is three rather than the decimal-looking text eleven, and record any precise question or lookup used.

Check your attempt: Check all eight rows and the place-value explanation

The complete table is 000 = 0; 001 = 1; 010 = 2; 011 = 3; 100 = 4; 101 = 5; 110 = 6; 111 = 7. The selected-weight forms are 0; 1; 2; 2+1; 4; 4+1; 4+2; 4+2+1. Thus 011 is 0×4 + 1×2 + 1×1 = 3; its symbols are a base-two place-value representation, not the base-ten text 11. Duplicate, omitted or unchecked rows remain partial even if the visible endpoints are correct. A correction counts only when the first output, exact question or reference and changed row remain visible.
