Teach one grid rule and let a fresh move test the explanation

Learning guide — unscored

Supplied three-by-three coordinate grid

Columns A, B and C run left to right. Rows 1, 2 and 3 run bottom to top. A coordinate gives column first, then row. Therefore B2 is the center cell and B3 is the top-middle cell. The first fresh case is A3; the post-revision case is C1. Use nine tactile or paper squares when a visual grid is not accessible. Orientation labels remain available; the learner is not tested on tiny print, speed or remembering an unstated origin.

Prepare the explanation without giving away the fresh move

Use the grid card to write a Version A explanation in no more than four sentences. It must name column-first order, left-to-right letters and bottom-to-top row numbers; demonstrate B2; and contrast B3 without mentioning the location of A3. Write one starting-knowledge question, one access question and the exact neutral prompt for A3. Identify two teacher behaviors that would reveal the answer before the learner commits. Preserve the plan before opening the key.

Check your attempt: Check the plan for rule, contrast and non-revealing prompt

A complete short explanation may say: “Coordinates name a column first and a row second. Columns A–C go left to right; rows 1–3 start at the bottom and go upward. For B2, choose column B and then row 2, the center. B3 stays in column B but moves to the top row.” The fresh prompt is simply “Please locate A3 and tell me how you chose it.” Pointing toward top-left or saying “top row” before commitment reveals part of the answer; moving the learner’s hand reveals it entirely. Starting knowledge and preferred representation must be asked, not inferred.

- Column-first order and both axis directions are explicit
- B2 and B3 show a meaningful contrast
- A3 remains unmodeled before commitment
- Starting knowledge access and answer-revealing behavior are addressed
