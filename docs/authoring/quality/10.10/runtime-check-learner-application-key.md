Teach one grid rule and let a fresh move test the explanation

Learning guide — unscored

Supplied three-by-three coordinate grid

Columns A, B and C run left to right. Rows 1, 2 and 3 run bottom to top. A coordinate gives column first, then row. Therefore B2 is the center cell and B3 is the top-middle cell. The first fresh case is A3; the post-revision case is C1. Use nine tactile or paper squares when a visual grid is not accessible. Orientation labels remain available; the learner is not tested on tiny print, speed or remembering an unstated origin.

Run or analyze the two fresh applications

Preferred route: with a willing adult, use Version A, obtain a committed A3 response, ask what was uncertain, revise one supported barrier and request C1 without pointing. If no willing learner is available, use this supplied simulation and label actual learner evidence untested: after B2, the learner asks “Do rows start at the top?”; the teacher points at A3 before commitment; the learner selects it. The teacher then revises, “Row 1 starts at the bottom edge and rows count upward,” and the learner selects C1 without a hint. Classify both attempts, the prompt, the revision and what the simulation can and cannot establish before opening the key.

Check your attempt: Check the fresh moves and evidence boundary

A3 is the top-left cell. In the simulation, pointing before commitment makes that response prompted, so it cannot show independent application. The question about row origin identifies a plausible explanation gap but does not diagnose the learner. The revision explicitly anchors row 1 at the bottom. C1 is the bottom-right cell; the simulated unhinted selection is consistent with the revised rule. Because the record is fictional, both events support analysis of a teaching response—not an actual learner outcome. A live willing learner’s actions must be recorded separately if they occur.

- A3 and C1 are located correctly
- The answer-revealing prompt limits the first result
- The revision addresses the stated row-origin uncertainty
- Simulation rehearsal and actual learner evidence remain distinct
