Retrieve, repair and version one short sequence

Learning guide — unscored

Supplied fictional target and three chunks

Target V1, revision 1, 8 September 2026: (1) enter at the west door; (2) check in at the desk; (3) collect a purple pass; (4) go to room four; (5) return the pass to the blue box; (6) leave by the same west door. The suggested chunks are arrival [1–2], visit [3–4], departure [5–6]. The chunk labels are aids, not replacement answers: order, object, color, number and repeated exit door still matter. This is a fictional memory target, never a real access or safety procedure.

First retrieval after a real short break

Read or hear Target V1 once and create one cue route. Put the complete target away. Do an unrelated activity for at least five minutes; record the actual times rather than estimating a delay. Then write or say all six steps in order without the reference. Mark U, C, L, O or W for every position before opening the key. A cue may be used, but label it. Stop after one preserved response; repeated guesses are practice, not the first attempt.

Check your attempt: Check the first response position by position

V1 in exact order is: west door; desk check-in; purple pass; room four; blue box return; same west door exit. Award one exact-position item only when the object, distinguishing detail and order are correct. “Door, desk, pass, room, box, door” preserves categories but omits west, purple, four and blue; it is not 6/6. “West door, desk, room four, purple pass, blue box, west door” has positions 3 and 4 reversed. Report U/C/L/O/W separately; C and L can support learning but are not unaided recall. A valid repair names the exact failed feature and changes one cue after preserving the response.
