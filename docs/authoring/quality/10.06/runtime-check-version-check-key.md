Retrieve, repair and version one short sequence

Learning guide — unscored

Supplied fictional target and three chunks

Target V1, revision 1, 8 September 2026: (1) enter at the west door; (2) check in at the desk; (3) collect a purple pass; (4) go to room four; (5) return the pass to the blue box; (6) leave by the same west door. The suggested chunks are arrival [1–2], visit [3–4], departure [5–6]. The chunk labels are aids, not replacement answers: order, object, color, number and repeated exit door still matter. This is a fictional memory target, never a real access or safety procedure.

Delayed retrieval and one controlled version change

On the next calendar day, or after the longest honest delay available, retrieve V1 before looking and preserve the actual response and delay. Then read Target V2: only step 4 changes from room four to room six; every other word and position remains V1. Put both versions away and produce V2 once. Label whether step 4 came from V2, interfered from V1, used a cue or was looked up. List any other position that changed accidentally. If the delay did not occur, label this a prepared future check, not delayed evidence.

Check your attempt: Check original and changed versions without blending them

V1 remains west door, desk, purple pass, room four, blue box, west door. V2 is identical except position 4 is room six. Saying room four in the V2 attempt is old-version interference, not a correct answer because it was once learned. Changing purple to another color or blue box to another container is collateral error. A completed record includes the actual delay and retrieval route for both attempts. When no delay occurred, the correct disposition is prepared or immediate practice—not a delayed pass. A clean V2 response supports only this controlled version update under recorded supports.

- V1 and V2 differ at exactly one declared position
- Old-version interference is visible
- Unplanned changes at other positions are retained
- The actual delay controls the evidence label
