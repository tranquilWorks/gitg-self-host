# 10.02 — Improve one weak component with fixed criteria and one correction

Isolate a safe skill component, record a bounded baseline, use criterion-based feedback and retry under comparable conditions without equating time spent with improvement.

Practice one safely bounded component using a fixed standard, a baseline attempt, specific feedback and a comparable retry. The evidence concerns that component under the recorded conditions; it does not establish mastery of a larger skill. Use the comparison to choose the next correction or a reason to pause.

Use a blank spreadsheet or the supplied paper route, with synthetic values only. The learning guide supplies exact cell locations, four fixed criteria, a different worked example, a baseline prompt, a comparable retry and separately revealed checks. Copy the private attempt record first. Keep the two timed attempts at the same difficulty and with the same supports. No paid software, coach or private data is needed.

About forty-five to sixty minutes across planning, two five-to-fifteen-minute attempts and one feedback pass within fourteen days.

Use paper, slower pacing, an accessible input method, a model or a freely consenting coach. Keep adaptations present in both attempts where possible. Exclude hazardous equipment, driving, clinical rehabilitation, regulated practice and coerced public evaluation.

## 1. Define one component and fix its success criteria

Choose the supplied four-cell summation component. Read the guide’s method and contrasting example, then copy criteria C1–C4 and the attempt record before opening Baseline. Choose a five-to-fifteen-minute limit and a spreadsheet or paper route. In a spreadsheet the skill is selecting a live input range, not typing a known total. On paper it is including exactly the intended addends and recalculating after a change; automatic spreadsheet updating remains untested. If the method is already routine, use the supplied harder-route plan for a future cycle instead of inventing errors or claiming this is your weak component.

- One observable component is selected
- Two to four criteria are fixed before the attempt
- Difficulty time and feedback method are safely bounded
- Synthetic material and a privacy boundary are selected

## 2. Make a baseline attempt without changing the target

Open Baseline and make one attempt within the chosen interval before revealing its check. Preserve the original formula or written addition and the result before and after the input change. Then check C1–C4 individually and record observed criteria divided by four, including zero if none are observed. Keep the actual duration, aids and errors in the private attempt record. Stop at the declared limit. Use only the application’s existing bounded indicators; do not paste spreadsheet content or recordings into evidence.

- A real bounded baseline attempt occurs
- The observed fraction uses the fixed criterion count
- The attempt ends at its declared limit
- Errors and support conditions remain visible

## 3. Select exactly one feedback correction

Use the Baseline check and diagnostic examples to identify one missed or unstable criterion and one correction. For an omitted endpoint, trace the first and last selected input before accepting the formula; for a typed total, replace it with a reference-based calculation and test an input change. Keep other conditions fixed and record the chosen correction before retrying. If all criteria were met, say so and test a preventive check without inventing weakness. A freely willing reviewer may check the same criteria; keep their identity and comments private.

- Feedback uses the criteria fixed in advance
- One missed component and one adjustment are selected
- The retry condition is defined explicitly
- Feedback is voluntary private and free of humiliation

## 4. Retry once and compare performance rather than effort

Open Comparable retry and use its new four-value dataset with the same criteria, time limit, tool and supports, plus the one chosen correction. Keep the attempt before revealing the retry check; record the observed fraction out of four and actual duration. Compare each criterion with baseline, allowing improved, unchanged, worse, mixed or not comparable. Do not add repetitions or raise difficulty within this retry. Only after reviewing the comparison, choose the guide’s concrete next-cycle progression or a reason to pause. Improvement on this small component does not establish transfer to a larger skill.

- A comparable or easier retry is actually attempted
- The same criterion denominator is used both times
- Unchanged worse and improved results are all permitted
- The next progression decision follows the observed performance

Repair one summation error and compare a fresh retry

Learning guide — unscored

Practice a component, not just a duration

A component is a small operation you can inspect separately. Here it is selecting exactly four input cells for a sum and keeping the result linked when an input changes. First fix success criteria, preserve a baseline, obtain criterion-specific feedback, choose one correction and retry with comparable inputs. Difficulty should permit harmless mistakes while letting you inspect what went wrong. A single improved retry is a useful observation, not proof that practice caused lasting improvement. This original exercise is not a validated training program.

Example on different cells

For an example, put 2 in B1 and 6 in B2. In B3 enter =SUM(B1:B2); the result is 8. The colon names the inclusive range, from the first endpoint through the last. If B2 changes to 7, the result becomes 9. Typing 8 into B3 produces the original total but will not update; =SUM(B2:B2) omits the first input. On paper, write 2+6=8, cross-reference each addend to its input, then write a separate 2+7=9 after the change. Paper tests selection and recalculation, not spreadsheet behavior. Restore any changed input before starting another attempt.

Four criteria fixed before the attempt

C1 — The calculation includes every one of the four designated input cells or paper values exactly once.
C2 — It excludes the unrelated value and the result cell itself.
C3 — The first result equals the independently checked total for the original input set.
C4 — After changing only the designated last input, the same spreadsheet formula updates to the correct new total; on paper, preserve the original and make a correct separate recalculation.

Use observed / not observed / uninspected for each criterion. A correct number alone does not establish C1 or C2: inspect the formula or written addends. The recorded fraction is the number observed divided by four, with uninspected criteria excluded from the numerator. Retain uninspected separately from inspected failures; if a comparison depends on an uninspected criterion, mark that comparison inconclusive. Turn a failed criterion into one correction

If an endpoint is missing, trace the source list from its first through its last intended input. If an unrelated cell is included, compare the selected range with the four permitted inputs. If the formula is correct but the total differs, inspect the entered values before changing the method. If the total stays fixed after the change, inspect whether you entered a number rather than a live formula. Choose exactly one correction supported by the preserved output, not a new goal such as speed or attractive formatting. If all criteria were met, report no demonstrated weakness; a preventive check can test maintenance but cannot establish improvement.

Keep the access route honest

Use zoom, a screen reader, keyboard navigation or speech entry already available to you. Preserve these supports in both attempts. If cell navigation is unfamiliar, use paper for the complete default; learning an unfamiliar interface is a different component. State when a helper supplies the formula rather than only entering your dictated response. Extra help on retry can be useful, but it prevents attributing the difference solely to your correction. Never use consequential financial, medical or work data as practice input.

When and how to raise difficulty

Do not increase difficulty in the scored retry. If C1–C4 are reliably met with comparable supports, plan a separate future cycle that changes only input selection: put 4, 6, 8 and 10 in A1, A3, A5 and A7; put unrelated 100s in A2, A4 and A6, and place the result in A8. Keep the same four criterion meanings and change the last intended input from 10 to 11 for C4. Before attempting, fix the same time limit and checking route; inspect each selected reference, then independently add only the four intended values on paper to check both totals. This introduces nonadjacent selection, not larger numbers, speed or more criteria at once. If the original component still fails, repeat a new comparable cycle with the specific correction instead. Stop when tired or frustrated; more elapsed practice is not itself a better result.

Baseline: include the right cells
