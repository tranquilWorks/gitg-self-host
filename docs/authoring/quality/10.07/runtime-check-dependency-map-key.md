Supplied five-folder rule and six slips

Today is Monday. Five folders are labeled TODAY, THIS WEEK, WAITING, REFERENCE and ARCHIVE. Apply the first matching rule: (1) completed or expired → ARCHIVE; (2) explicitly waiting on another person → WAITING; (3) an open action due today → TODAY; (4) an open action due Tuesday through Sunday → THIS WEEK; (5) reusable information with no action → REFERENCE. Supplied slips: A completed receipt; B waiting for Pat’s approval, due today; C submit form, due today; D call supplier, due Thursday; E torque table, no action; F expired coupon. Correct folders are A Archive, B Waiting, C Today, D This Week, E Reference, F Archive. The precedence rule resolves B’s overlap.

Build the dependency map before seeing the key

Using the five-folder rule, place these component cards in a defensible dependency order: R read the slip fields; P apply precedence; F choose a folder; D demonstrate and name the deciding rule; Q ask the learner to classify a fresh slip and explain why. Draw at least four directed links and state why each is required. Then classify supplied slip B and identify the exact misconception that would occur if due date were checked before waiting status. Preserve the map before opening the key.

Check your attempt: Check the minimum dependency structure

A minimal valid chain is R → P → F → D → Q: fields must be read before precedence can be applied; precedence selects the controlling rule; a folder follows that rule; a demonstration must expose the rule used; and a fresh question can then test application. Additional links such as R → D are defensible when explained. Slip B belongs in WAITING because rule 2 is the first match after it is confirmed open; checking due date first would incorrectly send it to TODAY. A list without directed dependency reasons is partial, even if its order happens to match.

- Four or more justified links connect the components
- The precedence misconception is identified
