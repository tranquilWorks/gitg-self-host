# 10.07 — Break a complex skill into prerequisites and an integration test

Build a small learning path with dependencies, component exercises, measurable milestones and one attempt that reconnects the parts.

This designs and pilots a path for a harmless beginner skill. It does not establish expertise, authorize regulated work or assume that every component can be learned independently.

Default skill: give a clear three-minute explanation of how to organize five labeled paper folders. Components are choosing the audience’s goal, ordering steps, demonstrating one example, checking understanding and staying within time. Materials are five paper labels, a page and an optional timer; speaking can be replaced with an accessible written demonstration.

Thirty minutes to map the skill and two fifteen-minute practice periods.

## 1. Map the output and the dependencies that make it possible

Define done as a listener or reader being able to file a new labeled slip correctly. Put the five components on cards and connect prerequisites: the filing rule must be clear before a demonstration can illustrate it; a check question must match the taught rule. Mark one component you can already perform and one that needs work. Do not equate familiarity with having demonstrated it.

- The final skill has an observable success condition
- Prerequisites and dependent components are connected
- Current ability is distinguished from untested confidence
- One weak component is selected for initial work

## 2. Create a progression with supplied component exercises

Use three milestones: write a four-step sequence with no missing object or location; demonstrate it on one slip without skipping a step; then ask a new filing question and correct one confusion. Attempt the first weak milestone now and compare it with the stated criterion. Increase complexity only after the criterion is met, or reduce the component while keeping its purpose when it is not.

- Each milestone has an observable criterion
- At least one component exercise is attempted
- Progression follows demonstrated performance
- A failed milestone leads to a smaller or revised exercise

## 3. Run one integration attempt and find the broken handoff

Combine the components into a three-minute explanation or equivalent short written guide. Use a willing adult learner when available; otherwise follow the guide literally yourself and label the check self-review. Test a new slip, note where the sequence or explanation failed, and move that weakness back into the learning path. Finishing each component separately is not assumed to prove that they work together.

- The components are recombined in an actual attempt
- A new example tests more than memorized wording
- Learner feedback and self-review are distinguished
- An integration failure changes the next practice step

Use written, signed, visual or AAC-supported explanation and an untimed version when timing is not part of the real skill. A willing reviewer is optional, but independent learner success must not be claimed from self-review.

Decompose one filing explanation and reconnect it in a new case

Learning guide — unscored

Components need dependencies and a whole-task check

Decomposition turns a complex performance into observable components without pretending the pieces are independent. A prerequisite must be available before a dependent step can work. A milestone states a visible criterion, not time spent. Part practice isolates one weak component; integration reconnects the pieces and tests their handoffs on a fresh case. Completing every card separately does not establish the whole skill. This bounded design exercise does not certify teaching ability, expertise or permission for regulated work.

Supplied five-folder rule and six slips

Today is Monday. Five folders are labeled TODAY, THIS WEEK, WAITING, REFERENCE and ARCHIVE. Apply the first matching rule: (1) completed or expired → ARCHIVE; (2) explicitly waiting on another person → WAITING; (3) an open action due today → TODAY; (4) an open action due Tuesday through Sunday → THIS WEEK; (5) reusable information with no action → REFERENCE. Supplied slips: A completed receipt; B waiting for Pat’s approval, due today; C submit form, due today; D call supplier, due Thursday; E torque table, no action; F expired coupon. Correct folders are A Archive, B Waiting, C Today, D This Week, E Reference, F Archive. The precedence rule resolves B’s overlap.

Example decomposition on a different sorting rule

A learner explaining a three-bin book return first defines done: a new card reaches the correct bin and the learner can state the deciding field. They identify prerequisites—read return date before comparing it with today—and practice that comparison alone. Their milestone is four supplied cards classified with the deciding field named. In the whole-task check, an overdue reserved book exposes an untested precedence between “overdue” and “reserved.” The path returns to that handoff rather than claiming that separate card success proved integration.

Progress from rule use to demonstration to integration

Milestone 1: classify A–F with the deciding rule and at least 5/6 correct, with B necessarily correct. Milestone 2: explain the precedence rule and demonstrate B and one non-overlap slip without silently correcting yourself. Milestone 3: give the full explanation, then let a fresh slip test the learner’s application. If B fails, practice precedence before presentation polish. If the fresh case fails, locate whether the rule, example, check question or handoff failed. Timing is descriptive unless the real requirement makes it essential.

Adapt representation without changing the rule

Use large labels, color plus text, tactile folder markers, screen-reader-friendly text, signing, speech or AAC. Remove the timer when speed is not part of the target. A helper may manipulate cards while the learner chooses the rule and folder. Record a self-run as self-review rather than learner evidence. An advanced route may add one documented exception only after the base precedence works; consequential records, regulated filing and private workplace material are outside this default.

Send the observed failure back to one component

If G is classified and explained correctly without rescue, test one new non-overlap case before adding complexity. If the folder is right but the reason is wrong, practice naming the deciding rule. If the explanation omits precedence, revise the rule-order component and rerun a new overlap slip. If representation blocked access, change the medium while retaining the decision criterion. Record demonstrated, partial, adverse or inconclusive; do not advance from confidence or component count.
