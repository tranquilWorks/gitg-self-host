Learning guide — unscored

Supplied ambiguous instruction and intended result

Folders: TODAY, LATER and REFERENCE, arranged left to right. Objects: one blue slip labeled “due today” and two unmarked white slips, all initially in a row below the folders. Version A instruction: “Put the blue slip in the correct folder and leave the rest there.” Intended result, kept separate from Version A during the literal test: the blue slip is inside TODAY; both white slips remain in their original row below the folders. A test succeeds only if both destination and non-target location are unambiguous from the instruction, not from private knowledge of the intended result.

Test Version A before repairing it

Hide the intended-result paragraph from a willing adult tester, or run Version A yourself literally without supplying missing assumptions. Preserve where the blue slip was placed, what happened to each white slip, and every clarification request. Ask “Which words determined the destination and where the other slips stay?” rather than “Did you like it?” Identify all supported gaps, then select the most consequential one for a single correction. Do not open the key before recording Version A.

Check your attempt: Check what Version A can and cannot specify

Version A does not name TODAY and “the correct folder” depends on a rule the tester was not given. “Leave the rest there” has an unclear referent and location: there could mean beside the blue slip, in a folder or in the original row. A tester who happens to produce the intended result does not make the wording unambiguous. The first output must remain visible. Relevant feedback names one of those textual gaps; “make it prettier” is unrelated to the fixed semantic target. A complete selected correction must eventually specify both target destination and non-target location.

- Destination and non-target-location gaps are identified
- Lucky success is not treated as clear instruction
- Feedback is connected to preserved output and text
- One semantic correction is selected before retest
