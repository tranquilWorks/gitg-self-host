# 10.05 — Build, retrieve and revise one source-linked note for a later problem

Capture, compress, connect and retrieve a small piece of knowledge, then revise the note after attempting to use it on a new task.

This tests a minimal knowledge system, not a requirement to build a large archive or adopt a particular application. Stored volume is not evidence of learning or usefulness.

Use the supplied averages source card, atomic-note template, three-entry index and delayed application. Paper, local text, audio or another accessible private medium is sufficient. Keep the source label, your own compressed explanation, a worked example, one meaningful connection, a retrieval cue and a revision history; no particular note application or large archive is required.

Twenty minutes to make one note and fifteen minutes to retrieve and apply it several days later.

## 1. Capture only enough to answer a future question

Read the supplied source card, then close it and draft one note with a descriptive title, source label, own-words explanation, worked 1-2-9 example, future-use question and retrieval cue. Reopen the card, correct any distorted definition or arithmetic and retain the original correction. Complete the note-quality prompt before revealing its rubric. Do not copy the entire card or replace a missing idea with decorative formatting, links or a large tag hierarchy.

- The note has a findable descriptive title
- Definitions and example are compressed accurately
- The source can be identified
- A concrete future-use question guides what is retained

## 2. Connect the note to one existing task and test retrieval

Add the note to the supplied three-entry index under one meaningful work or learning context. Close it and use only the declared cue or index to find it; record found, found with alternate route, not found or support needed, plus the actual route. Explain the example without reading every sentence, then distinguish retrieval of the note from unaided recall of its contents. Repair one barrier such as an ambiguous title, broken locator or unexplained connection and retest once.

- One meaningful task connection is explicit
- The note is found through its intended retrieval route
- The connection is not merely an unexplained tag
- A discovered retrieval barrier is corrected

## 3. Use it on a new problem and revise its weak point

After an actual delay when feasible, use the index to find the note before opening the application key. Apply it to 2, 3, 4, 5 and 16; preserve calculations, units, interpretation and any content help. Explain which summary is pulled by the extreme and what neither number says about spread. Open the key, then append one precise correction, limitation or better cue with date and reason. Same-session use is practice but must not be labeled delayed retrieval.

- A delayed retrieval is attempted
- A new problem is solved using the note
- The note’s limitation is identified during use
- A specific revision improves future retrieval or application

Use an audio note, large print, a tactile index or a single accessible document. External supports are legitimate; distinguish finding a note from unaided recall. Use non-sensitive examples and avoid automatically syncing confidential material.

Make a small knowledge system prove itself through reuse

Learning guide — unscored

Notes are interfaces to sources and future work

Capture records a source and relevant facts. Compression rewrites enough meaning to be useful without copying everything. Connection names where or why the idea matters; a tag with no explained relationship is not a connection. Retrieval uses a cue or index that can be tested. Revision changes the note when use reveals an error, omission or poor route. A sustainable system minimizes maintenance while preserving provenance, findability and use. Finding a note is different from recalling its contents without help, and a large archive is not evidence that either occurred.

Supplied source card — comparing averages

Source S1, “Small-set summary definitions,” Grounded Growth fictional teaching card, revision 1, 8 September 2026. Mean equals the sum of all values divided by their count. Median is the middle value after sorting an odd-sized set; for an even-sized set it is the mean of the two middle values. For 1, 2 and 9 minutes, mean = (1+2+9)/3 = 4 minutes and median = 2 minutes. The high value pulls the mean above the median. Neither summary alone describes the full spread; range or the original values may still matter. This card is supplied instructional material, not an external research source.

Atomic note and revision template

Note ID and findable title: __. Source ID, title and revision: __. In my own words: __. Worked example with units: __. Meaningful connection—this helps when __ because __. Future-use question: __. Retrieval cue or index path: __. Known limit: __. Revision log: date | observed problem | exact change | reason. Keep one idea cluster that can stand alone; split the note only when two parts need different sources, cues or revision histories.

Three-entry retrieval index and test log

The fictional index begins with: Planning estimates → Comparing averages → Note N1; Shopping quantities → Unit conversion → Note N2; Reading queue → Source triage → Note N3. Replace N1’s title/path with your final choice but leave N2 and N3 as distractors. Retrieval test: cue used | expected note | found / alternate route / not found / support needed | elapsed band [under 1 minute / 1-3 / over 3] | barrier | repair | retest result. Time is diagnostic only, not a score, and accessibility support remains available.

Worked note that is compressed, connected and limited

N1 — “Mean reacts to extremes; median uses sorted position.” Source S1 rev 1. Mean shares the total across all observations; median selects the middle position after sorting. For 1, 2, 9 minutes: mean 4, median 2. Connection: when one planning estimate is unusually high, compare both before presenting a typical duration. Future question: which summary changes more if only the highest value increases? Cue: Planning estimates → Comparing averages. Limit: neither value reports the full spread. This example supports later use without reproducing the entire source card.

Keep the function while changing the medium

Use paper, local text, audio, images with alternative text, tactile labels or a supported index. A helper may operate the medium while the learner chooses the title, source, explanation, connection and revision. Advanced users may use a real technical note and test it against a new problem, but confidential or licensed source material must stay in an authorized system. If the default arithmetic is already routine, raise conceptual novelty, not archive size or software complexity.

Progress through spaced reuse and selective maintenance

Reuse the same note in another genuine task, or create one new note with a different source and retrieval route. Periodically sample whether notes can be found and applied; revise or retire failures instead of reorganizing everything. This exercise observes one note, one route and one application. It does not establish long-term retention, broad knowledge management ability or the superiority of one note-taking method.
