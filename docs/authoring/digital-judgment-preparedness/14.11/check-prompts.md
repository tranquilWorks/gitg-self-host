# Fresh checks

1. A commercial advertisement uses a BY-NC image and includes impeccable credit. Does the credit solve the permission issue? Would a voluntary donation automatically solve it?
2. A project copies a substantial MIT-licensed code component but keeps only the author's name and removes the copyright/permission notice. What needs repair?
3. A creator is paid for a single-use flyer image. The buyer wants to upload it to a reusable template library. What evidence is needed, and what should happen while it is absent?
