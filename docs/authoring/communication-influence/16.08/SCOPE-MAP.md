# 16.08 — Individual canonical scope map

**Canonical competency:** Classical and modern rhetoric

**Scope (unchanged):** Understand ethos, pathos, logos, framing, narrative, evidence, repetition, medium, and audience psychology.

**Evidence of progress (unchanged):** Can analyze persuasion and create an argument without concealing material truth.

| Canonical facet | Teaching and supplied work | Inspectable output | Remaining breadth / limit |

| Framing, narrative and repetition | Trial versus permanent garden; imagery and repeated limits | Device map and revised proposal | No fabricated benefit or repeated unsupported assertion |
