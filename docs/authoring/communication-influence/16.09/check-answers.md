# 16.09 — Corrective answers

1. Compressing the same material into less time can damage comprehension and access. Identify the audience's essential action, remove nonessential content, strengthen transitions and rehearse the edited version. If accommodation requires more time, agree and record that separately; the numerical target is not proof of delivery quality.
2. Use the actual sequencing error to revise the relevant transition or example, then ask for another uncoached account. Applause shows a reaction, not correct procedural understanding. Do not redesign a successful section merely because it is easier to polish.
3. For example: “That policy isn't in the material I verified. I need to check with the responsible organizer before giving you an answer.” Clarify the question and use an authorized follow-up route if available. The answer remains pending until actually verified; confidence cannot fill the gap.
