# 16.02 — Fresh checks

Answer before opening the corrective key.

1. A colleague says, “I know you want the notes before 11:00; I can't do that, but can send them at 14:00.” What is established, and what must you decide before replying?
2. Rewrite “If you respected me, you'd stop changing things” using only these facts: a shared agenda changed twice after you printed it; you need a stable copy by 16:00; you control when you print, not whether others edit.
3. Your message reader thinks your optional request is an instruction from the organizer. What should change, and what would constitute a useful retest?
