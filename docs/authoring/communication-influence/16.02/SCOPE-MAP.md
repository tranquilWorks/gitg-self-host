# 16.02 — Individual canonical scope map

**Canonical competency:** Clear and direct expression

**Scope (unchanged):** State observations, reasoning, feelings, needs, requests, and boundaries without hints or unnecessary complexity.

**Evidence of progress (unchanged):** A difficult message is understood without requiring others to decode it.

| Canonical facet | Teaching and supplied work | Inspectable output | Remaining breadth / limit |
| --- | --- | --- | --- |
| Observations and reasoning | Event/interpretation separation and the missed-return causal effect | Planning note and disputed-history extension | No invented motive or documentary proof |
| Feelings and needs | Optional first-person feeling; dependable access distinct from one strategy | Own concern and practical need | No forced disclosure or universal directness norm |
| Requests and boundaries | Feasible return choice and authority over future lending | Message and accepted/declined/counteroffer statuses | Understanding does not mean compliance |
| No hints or unnecessary complexity | Uncoached reader identification and revision | First version, decoding error, revised message | Self-review is not recipient evidence |
