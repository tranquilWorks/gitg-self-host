# 26.05 — Fresh checks

Attempt these before opening [answers](check-answers.md).

1. A fresh route takes 7 minutes out and 7 back with a 4-minute pause, starting 10:10 and due back 10:30. What return time is planned, and does two minutes of slack certify safety?

2. At 09:18 the only onward path has unconfirmed conditions; the known return from J takes 6 minutes. What is the supported choice and projected return? No actual return record is supplied.

3. A participant reaches the entrance at 09:14 but the promised message is unsent. Can the contact arrangement be marked complete?
