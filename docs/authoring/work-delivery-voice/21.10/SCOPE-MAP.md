# 21.10 — Individual canonical scope map

**Canonical competency:** Innovation and improvement

**Scope (unchanged):** Question assumptions, combine ideas, run experiments, and improve value without fetishizing novelty.

**Evidence of progress (unchanged):** A tested change creates measurable benefit or useful learning.

| Canonical facet | Teaching and supplied work | Inspectable output | Remaining breadth / limit |
| --- | --- | --- | --- |
| Question assumptions and combine ideas | Memory versus visible labels and current marker | Predicted correctness and checking benefit | Newest or marked is not necessarily approved |
| Run experiments | Four five-candidate sets and known ledger answers | Baseline 2/2, changed 1/2; seven versus zero openings | Order, bundled change and case effects unresolved |
| Value and cost | Correctness separate from checking and burden | Six setup plus two reconciliation minutes | No elapsed selection time or future cost known |
| Useful learning without novelty worship | Owner declines marker and considers register test | Revised proposal untested and unadopted | No production improvement or causal effect |

Read the [learner guide](learner-guide.md), save an attempt before the [later packet](later-packet.md), and attempt [fresh checks](check-prompts.md) before [corrective answers](check-answers.md). See [sources](../SOURCES.md) and [individual review](../QUALITY-REVIEW.md).

Canonical classification: applicability context_sensitive; normative status cross_tradition_core_or_broadly_recurrent; formation modes: agency, stewardship, interdependence.

The canonical record has no professional_boundary field. Practical exercise safeguards do not add canonical metadata. Work learning does not compel paid employment, a career change, union participation, disclosure or unlimited availability. Fiction and no attempt are legitimate. Actual work requires the appropriate authority, consent and current qualified guidance where needed.

Canonical measurement boundary: Use at least two independent evidence types, including one behavioral, observer, artifact, objective, or longitudinal indicator; self-report alone is insufficient for score advancement. Preferred evidence types: performance_task, artifact, observer_feedback, objective_indicator. This is preserved metadata, not a new exercise scoring rule. Human dignity is never scored.

No runtime selection, action, evidence field, score, completion or participant record changes. Supplied fiction is not actual observer evidence. Formal M6K A/B/C, independent cold-start, actual learner, qualified and owner content acceptance remain pending; author review is not an acceptance receipt.
