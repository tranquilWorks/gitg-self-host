# Fresh checks

Attempt before [reading answers](check-answers.md).

1. A draft reaches its time limit with an essential fact missing. What should change first: the fact standard or the readiness claim?
2. An editable instruction has already been distributed. Does easy editing make every error easily reversible?
3. A harmless guide succeeds after nineteen minutes against a twelve-minute budget. Does that vindicate skipped checks on a hazardous task?
