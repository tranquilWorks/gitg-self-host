# Fresh checks

Attempt before [reading answers](check-answers.md).

1. A tool drafts four items in four minutes, while review takes six and repair takes three. Manual completion takes ten. Did the trial save six minutes?
2. Your release gate stops use for an invented time, but you already have three offline specimens. Can you examine the remaining specimens after pausing release?
3. A corrected reminder matches its facts, but the intended reader has not evaluated the requested format. Can you mark the accessibility condition passed?
