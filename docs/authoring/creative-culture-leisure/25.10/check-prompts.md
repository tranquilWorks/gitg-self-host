# Fresh checks

Attempt before [reading answers](check-answers.md).

1. A learner read a catalogue and transcript, then writes “I saw thick brushstrokes in the original.” What correction preserves the useful study?
2. Two works share a landscape subject. Is that enough to state that the first directly influenced the second?
3. A record credits a famous designer while an essay describes several production roles. How should an appreciation handle unnamed workers?
