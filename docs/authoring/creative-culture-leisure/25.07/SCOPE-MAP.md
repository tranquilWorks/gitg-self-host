# 25.07 — Individual canonical scope map

**Canonical competency:** Revision, finishing, and publication

**Scope (unchanged):** Define completion, edit, refine, present, and release work appropriately.

**Evidence of progress (unchanged):** At least one meaningful creation reaches an audience and produces feedback.

| Canonical facet | Teaching and supplied work | Inspectable output | Remaining breadth / limit |
| --- | --- | --- | --- |
| Define completion and edit meaning | Six-sentence V0 and V1; four criteria, bounded edits | Location/agency repair remains distinct from tense correction | Criteria do not dictate universal artistic quality |
| Refine, present and release | Complete V2 fixes tense; privately delivered in agreed plain text | Delivery is distinguished from initial no-response and later mixed reception | No actual audience or public release |
| Feedback from a meaningful creation | Misread warmth retained; V3 is explicitly unshared | Decision to finish and carry learning to another work | New sharing needs consent; no broad publication mastery |
