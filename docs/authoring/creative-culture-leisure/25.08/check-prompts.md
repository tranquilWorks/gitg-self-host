# Fresh checks

Attempt before [reading answers](check-answers.md).

1. A more experienced collaborator types the final file. Does that give them authority to publish both contributors’ work?
2. Two names appear on a draft, but only one person chose images, wording and structure. What remains unestablished?
3. Your collaborator likes the private version but has not answered a request to post it publicly. Can you treat their earlier approval as enough?
