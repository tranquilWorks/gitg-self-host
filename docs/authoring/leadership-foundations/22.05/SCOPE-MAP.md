# 22.05 — Individual canonical scope map

**Canonical competency:** Delegation and empowerment

**Scope (unchanged):** Match responsibility to readiness, provide context and authority, establish checkpoints, and avoid micromanagement.

**Evidence of progress (unchanged):** Others gain competence while real work progresses.

| Canonical facet | Teaching and supplied work | Inspectable output | Remaining breadth / limit |
