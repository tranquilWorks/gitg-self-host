# Fresh checks — account resilience

1. A fictional account requires a password and either a phone code or an unused printed recovery code. The phone is unavailable. The password vault opens only after signing into that same account. A printed code exists. Is recovery established? Trace the missing dependency.
2. A provider-supported test consumed one one-time code. The only paper copy contains that consumed code; no other valid unused code is confirmed. A report says “Offline recovery tested and ready.” Correct it and name a safe next step without removing working access.
3. An account's authentication test succeeded. Its device backup is encrypted, but the only known decryption key is on the device assumed lost in the disaster scenario. An unexpected approval prompt also arrives. Explain the backup limitation and the immediate response to the prompt without treating either as solved by the successful test.
