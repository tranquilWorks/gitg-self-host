# Fresh checks — data hygiene

1. The required note says “Workshop / Blue door / Bring gloves.” A retrieved file with the same name says “Workshop / Blue door / Bring goggles.” The tool reports success. What passed, what failed, and how should a correction preserve the evidence?
2. A learner makes two folders on one laptop, then claims their files are protected if that laptop is lost. Identify the shared dependency and a bounded next test that requires no deletion or device reset.
3. An independent backup contains a Monday file. On Tuesday its only other copy is edited and synced, then deleted by a sync service with no version history. What version is known recoverable? What remains unknown, and why is a successful Monday restore not proof of Tuesday recovery?
