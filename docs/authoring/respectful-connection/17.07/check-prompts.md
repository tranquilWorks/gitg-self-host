# 17.07 — Fresh checks

Try these fictional cases before [the key](check-answers.md).

1. A host introduces a newcomer by sharing a private reason they have been isolated, hoping to make everyone kind. What went wrong?
2. The venue has a level entrance, but the invitation points everyone to a locked stair entrance. Is the building feature enough to establish usable arrival?
3. A participant says the quieter room helped but the unexplained game rules still prevented joining. How should you describe the result and next action?
