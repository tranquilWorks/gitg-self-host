# 17.01 — Fresh checks

These fictional cases have a separate [corrective key](check-answers.md).

1. A cashier answers politely while a queue grows. Is that a good reason to continue asking personal questions?
2. An acquaintance says, “Good to see you; I only have a minute.” How can you honor both the warmth and the limit?
3. You rehearsed an opening but did not approach anyone. The next session is available. What is the honest attempt status and next step?
