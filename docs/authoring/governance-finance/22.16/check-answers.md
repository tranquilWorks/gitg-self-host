# Corrective answers

1. The original decision-maker controls the reviewer’s position, so independence and corrective authority are doubtful. Use the actual governing process to establish a sufficiently independent appointment and conflict route; a new title alone does not fix the dependency.
2. Not merely by changing the rule later. Apply the rule valid at the relevant time and use the authorized correction process. Record a prospective effective date for any valid change; do not erase the original error.
3. Only if the actual governing rules give that authority. Otherwise record the unresolved review, protect affected people through permitted interim arrangements and use the legitimate appointment route. Access to the file does not confer decision rights.
