# 11.02 — Fresh checks

Write the plan and reason before reading the corrective guidance.

## Check A — Loudness is not a deadline

A fictional 100-minute window includes a protected ten-minute buffer. A 60-minute review was explicitly promised for today. An optional 30-minute poster request says “URGENT” but provides no needed-by date. A 30-minute solo leisure block is also desired. No shorter versions are supplied. The requester has not answered a timing question.

Make a feasible present plan and identify what must remain uncertain. Explain two possible defensible choices for the remaining 30 minutes, and what information would change your judgment. Do not assume that urgency is fake or that the optional requester has already agreed to delay. Would scheduling all three activities while excluding the buffer solve the problem?

## Check B — A reduced version needs a real agreement

A draft plan for 160 minutes lists O=60, M=30, R=30, G=15, buffer=20, and claims five spare minutes. Now the friend says a 30-minute visit would not work this time; the only agreed visit is 60 minutes. No other agreement has changed, and this visit is not an essential safety or care need.

Recalculate the plan using the actual agreed duration. State whether the original plan remains feasible. Propose a transparent renegotiation or deferral rather than silently retaining 30. Explain why a proposed new agreement must not be recorded as an accepted one before the friend responds.
