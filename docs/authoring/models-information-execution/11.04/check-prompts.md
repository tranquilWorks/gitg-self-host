## Check A — A circular plan and a missing agreement

A fictional event plan says “Choose an arrangement only after sending the final confirmation” and “Send final confirmation only after the arrangement is accepted.” Neither has happened. One participant has not replied. The host proposes resolving the blockage by marking both tasks complete and assuming the participant agrees.

Identify the dependency cycle and the missing external evidence separately. Repair the plan by distinguishing a provisional proposal from an accepted arrangement and final confirmation. Give a startable action that does not assume consent. What must remain blocked?

## Check B — Parallel logic is not extra workers

A paper-index project uses A=5 minutes, B=10, C=5, D=5, E=5. A has no prerequisites; B and C require A; D requires both B and C; E requires D. Tasks cannot be interrupted, and transitions take zero minutes in this toy calculation.

List all valid task orders for a single worker. Calculate total active work and the earliest possible completion with enough independent workers. Now B is revised to 8 minutes while all other facts stay fixed; recalculate both figures. Explain why the dependency graph does not, on its own, establish the availability of multiple workers or validate the duration estimates.
