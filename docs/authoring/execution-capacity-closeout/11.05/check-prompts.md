# Fresh scheduling checks

Save your own calculations before opening check-answers.md. These checks are fictional and unscored.

## Check 1 — Total time versus usable intervals

One person has free intervals 13:00–13:20 and 13:35–14:00. A task requires 30 uninterrupted minutes with the needed device available throughout both free intervals. A five-minute handoff must follow it and finish by 14:00. Can the task and handoff fit? Give the total free minutes, longest free interval, latest task start and a useful next decision. No one has agreed to move the 13:20–13:35 duty.

## Check 2 — A buffer can be spent once

A 120-minute window contains 75 minutes of planned work, 15 minutes of protected recovery and 30 minutes of reserve. Interruption X uses 20 reserve minutes. Interruption Y then needs 15. Work includes an optional 10-minute task that has not started and has no external commitment. Calculate the shortfall, move that optional task if necessary, and state the remaining free minutes and task status. Is keeping all 30 original reserve minutes on the revised calendar valid?
