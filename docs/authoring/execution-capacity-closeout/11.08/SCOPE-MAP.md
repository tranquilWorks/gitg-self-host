# 11.08 — individual canonical scope map

Canonical name: **Follow-through and accountability**.

Canonical scope: Review commitments, communicate risk early, and complete or renegotiate what was promised.

Canonical progress signal: Others and future self can reliably plan around commitments.

The source addresses the facets below. All are teaching responsibilities; actual situations and live routes remain conditional on role, capacity, access, consent and safety. The default is a bounded practice, not proof of the whole competency.
