# Fresh workflow checks

## Check 1 — WIP and missing input

A solo worker has agreed to create a printed route card. Card A (scope) is Done with a saved agreement. B (draft) is Doing. C (print) depends on B and printer access; access has not been confirmed. D (inspect print) depends on C. The WIP limit is one. A colleague Lee has not agreed to help. Give the honest states, what each blocked card lacks, and who can own seeking printer access. Can Lee be assigned printing or can C be moved to Doing to make the board look active?

## Check 2 — Rework and changed acceptance

A paper map was marked Done after two successful checks on Version 1. Its author then changes a location in Version 2, which fails one check. The requester says, “That location must remain correct; please fix it.” Classify the deliverable, preserve the version history, identify the next work and the acceptance test needed to close it. Is changing the original done rule from two correct locations to one an acceptable repair?
