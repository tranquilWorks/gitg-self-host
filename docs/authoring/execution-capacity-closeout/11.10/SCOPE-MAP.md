# 11.10 — individual canonical scope map

Canonical name: **Saying no and ending responsibly**.

Canonical scope: Decline low-value demands, release obsolete goals, and close projects or relationships cleanly.

Canonical progress signal: Attention is reclaimed without leaving unnecessary confusion, guilt, or neglected obligations.
