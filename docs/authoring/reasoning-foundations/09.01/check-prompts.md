# 09.01 — Fresh checks

Use the reference in the learner guide. Save each answer before opening the separate answer file. These fictional packets are self-contained; no real contact is required.

## Check A — A room booking

At 09:00, Robin sees that a calendar entry for Room C is marked cancelled. Robin says, “I feel embarrassed.” Pat says, “The coordinator cancelled it because she dislikes your group.” The packet contains no coordinator message or access log. Robin writes, “We will never get a room, so this project cannot continue.”

Classify these six claims, preserving provenance and explaining each boundary:

1. At 09:00 the calendar displayed a cancelled entry for Room C.
2. The coordinator personally changed the entry.
3. Robin reports embarrassment.
4. Pat attributes the cancellation to dislike of the group.
5. The group will never get a room.
6. The project cannot continue.

Name two unresolved questions. Write one fair clarification that does not require the coordinator to admit the claimed motive. Explain why the reported embarrassment neither establishes nor invalidates that motive.

## Check B — Revise without erasing

Initial packet: A tool is absent from its marked shelf at 16:00. The checkout sheet has no entry. Morgan concludes that Quinn stole it.

After Morgan writes a neutral location question, a staff member replies: “I moved it to Cabinet D during cleaning.” Morgan opens Cabinet D and sees the tool with the matching inventory number. Nobody witnessed the move in this packet.

Write an initial record and an appended revision. Identify one newly established observation, one attributed explanation, and one motive claim that remains unestablished. Choose a practical next step. Explain why finding the tool does not make the original accusation well-supported and why an uncertain motive need not prevent repairing that accusation.
