before opening `check-answers.md`. The separate files provide a source boundary;

## Reproduce the source checks

From the extracted bundle root or a checkout containing the same paths:

```sh
python -m unittest discover -s tests -p test_m6k_reasoning_sources.py -v
```

The tests use only Python's standard library. They inspect content structure and
exercise the fictional logic, numerical comparisons, source-attribution limits,
and unchanged runtime-count declaration. They do **not** run the application,
compiler, historical event replay, browser journeys, or database import. A passing
source test is not pedagogical effectiveness or independent reviewer acceptance.

`fixtures.json` is an instructional test fixture, not a production evidence or
scoring schema. The test-only decision function applies the supplied toy rule; it
is not a general recommendation algorithm. All records and participants are fictional.
