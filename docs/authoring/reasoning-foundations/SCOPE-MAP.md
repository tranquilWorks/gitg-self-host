Canonical scope: Separate events and evidence from assumptions, stories, emotions,
motives, predictions, and conclusions.

| Element | Teaching and practice | Fresh check / evidence limit |

| Events and evidence | Bounded observation versus attributed report; E1–E5 with explicit provenance | A: calendar display versus Robin's report and Pat's nested motive claim |

| Emotions | Alex's report preserved without treating it as Lea's attitude | A: embarrassment is not discarded or used as motive proof |
| Predictions | “She will never help” kept separate from observed silence | A: “never get a room” is not a current observation |
| Conclusions | “Activity doomed” evaluated as an inference, not a recorded fact | A: project impossibility does not follow from one display |
| Revision and progress indicator | Preserve the original; ask; append R1/R2-bounded changes | B: identify matching tool in Cabinet D while retaining the move's reported provenance |

The fictional artifact practices rewriting facts, interpretations, and unknowns.
It does not show live relationship repair, known motives, or global truthfulness.
A different reasonable category is acceptable when the role and limits are accurate.
