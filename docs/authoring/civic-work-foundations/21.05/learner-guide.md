# 21.05 — Quality, craftsmanship, and reputation

Build a small instruction whose care and finish fit its purpose, then test two comparable uses without silently rescuing the user. Allow twenty minutes to set criteria, one short writing session and a second-use check. Use paper room markers only. This task does not certify a real room, building layout, safety-critical deliverable or anyone's professional reputation.

## Quality depends on consequence and use

An artifact is good for a purpose in a context. A beautiful instruction that omits where to return equipment can create avoidable work. A correct but unreadable note may exclude its intended user. Care includes accuracy, understandable sequence, relevant exceptions and enough documentation for someone who was not present when it was made. Elegance can mean removing needless complexity while preserving what matters.

Start with the consequence of failure. In this paper task, a defect causes confusion or rework. Real access, fire safety, heavy furniture or equipment can have much higher consequences and require the responsible qualified owner. Do not use a harmless rehearsal's success to certify a real system or lower its standards. Establish the intended use and actual authority before choosing the quality bar.

Separate three kinds of effort. Necessary correctness includes the right room, arrangement and permitted route. Useful robustness includes a defined restoration state, an exception contact and a version that can be checked later. Some robustness is essential to this particular purpose, even if it is not part of the initial setup. Optional polish includes decoration that adds no useful distinction. A layer called “finish” is not automatically unnecessary; clear headings or readable contrast can materially help use.

Fix omissions that affect use before decorating. Compare facts with the authorized source and inspect the sequence as a stranger would encounter it. A restoration step should describe the final state, not say “put things back” when the reader never saw the original arrangement. If the source is silent, ask or mark the limit; do not create a plausible instruction and label it verified.

Repeatability requires checking another use. The first user may succeed because you explain a missing instruction, know the context or point at the intended object. That is an assisted result, not independent usability. Record where you intervened and correct the artifact. A second comparable attempt can test the revision, while changes in user or familiarity limit comparison. Do not hide the failed first use to present two smooth successes.

Reputation is a social judgment built from more than one polished sample. Consistent useful work can justify trust in a kind of output, while publicity and praise may say little about robustness. Ask whether the artifact met its intended purpose, not whether the user now regards you as a careful person. A defect is a reason to repair the work, not a score of human worth.

## Worked example

The author writes “restore the room after use.” A reader cannot know whether that means rows, stacks or storage. The author supplies the missing answer during the trial, then realizes the document did not carry its own context. A corrected restoration instruction makes the final state explicit. Decorative borders are deferred because they would not fix the missing operational information.

## Complete fictional paper-room specification

Use a paper grid with rows 1–4 and columns 1–4, six small paper chair tokens, one table token and an envelope labeled **NORMAL STORAGE**. This is a toy, not an actual accessible or safe-room layout. Room name is **Birch**; the paper door is at row 1, column 4. Keep column 4 empty as the specified route. Place chair tokens at row 2, columns 1–3 and row 3, columns 1–3, and the table at row 1, column 2. No other placements are authorized.

After the paper session, return all six chair tokens and the table token to NORMAL STORAGE; leave the grid empty. If a token is missing or the specified route cannot remain clear, stop and ask the fictional **Room Desk** instead of inventing a layout. The owner supplies these requirements for this exercise only. Use tokens A–F for the first trial and G–L for a comparable second set; both sets contain six chairs.

The intended reader must identify the room, follow setup, preserve the specified route, handle the missing-token condition and restore the normal state without author hints. Version the instruction so a correction does not silently overwrite what the first reader actually used.

## Build for use, then test again

1. State purpose, consequence and the full acceptance bar from the supplied specification. Sort effort into correctness, required robustness and optional polish. Output: criteria fixed before the artifact is judged attractive.
2. Write an instruction for someone absent from preparation, including the exact setup, exception and restoration. Check every fact against the source. Output: a versioned draft and one choice about useful versus merely decorative finish.
3. Try the first paper use with a willing reader or label a self-rehearsal accurately. Do not supply missing context during the attempt without recording it. Output: actual task result, intervention and defect list.
4. Save the draft before the [later packet](later-packet.md). Correct the defect and test the second comparable set without hints. Output: distinct first and second results with any changed conditions visible.
5. Decide whether another check or owner clarification is needed. Output: a bounded readiness claim for the paper task and unresolved limits, not a safety certification or durable reputation.

## Support and transfer

An accessible spoken instruction, tactile markers or larger labels can replace the visual grid. Keep the same meaningful criteria while changing the medium. A harder case omits the table token; the correct response is the specified stop/contact route, not creative substitution disguised as conformance.

For actual transfer, choose a harmless authorized document and preserve real safety, access, engineering and change-control requirements. Never move heavy objects or alter emergency access for a practice trial. A low-stakes artifact can teach care and checking, but high-consequence quality requires its own legitimate standards and evidence.
