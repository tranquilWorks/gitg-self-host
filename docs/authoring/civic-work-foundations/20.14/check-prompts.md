# Fresh checks

Attempt before [reading answers](check-answers.md).

1. Does agreeing to a private access request authorize publication of participants' stories or a protest on their behalf?
2. Is mediation the same as an imposed decision, and are a strike, boycott and public protest interchangeable steps in a universal ladder?
3. A readable notice is supplied but the only contact route is a narrow telephone window. What should the response recognize and preserve?
