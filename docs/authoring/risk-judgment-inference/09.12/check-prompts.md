# 09.12 — Fresh checks

## Check A — Same information, different result

Two fictional records have identical pre-choice facts, a documented uncertainty, the same reasonable objective, the same options, and the same selected option. Both were preserved before acting. Record X later reports completed; record Y reports not completed because of an event explicitly first announced after the choice.

May you conclude that X's choice-time process was better solely from these outcomes? Write a separate outcome review and one possible future contingency for each without changing the original expectation. Now add a new fact: Y actually had a relevant warning available before choosing and omitted it from consideration. Explain what changes in the process review and why this is not just punishing bad luck.

## Check B — Audit an altered and over-detailed record

A fictional learner's original dated copy predicts partly completed with moderate confidence. The later copy says completed with high confidence and contains a collaborator's name, private quotation, and exact personal circumstances. The learner says the change was only a clerical correction because the task ultimately succeeded. There is no separate change log. Another field says “review planned,” but no actual reminder was created for the real route.

Identify the distinct failures. Propose a repair that preserves the original, accurately labels what happened, avoids claiming retroactive scheduling, and keeps identifying material out of application evidence. Explain why hashing only the later copy cannot prove that its prediction existed before the outcome.
