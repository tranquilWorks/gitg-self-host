# Context, domain and independent creation

The source files contain many distinct cases and learning operations. That supports a narrower conclusion than “each was independently created and professionally validated.” Publication history and text differences do not prove the authoring process; the current acceptance ledger supplies no such certification.

Every competency has a canonical scope, source excerpt, exact source identity and nearest-text comparison in [audit.json](audit.json) and its [domain entry](README.md#competency-register). These are evidence available for inspection. All 383 primary texts and 275 companion-folder bundles were read. Each note describes the actual design; formal facet acceptance and proof of independent creation remain open.

## What the reuse scan does and does not show

All 383 primary texts were compared with all others: 73,153 pairs, zero exact normalized primary-body duplicate groups. The filtered lexical similarities are small, but that is **not** proof of 383 independent substantive designs. The method retains names and numbers and cannot catch all paraphrased templates. See [method and reproducible script](METHOD.md#text-reuse-and-semantic-comparison).

The catalogue repeatedly uses clubs, notices, room changes, paper sorting, bounded requests and later fictional replies. These can provide accessible low-stakes practice, and several comparisons above demonstrate genuinely different operations within them. Reuse becomes a quality defect when the setting substitutes for the domain's required expertise, when a beginner exercise becomes a universal default, or when changing the competency title leaves the same successful response. The original A1/A3/A5 and B4 criteria require checking that distinction per competency; neither template counts nor lexical thresholds close it.

A defensible acceptance packet would preserve the exact lesson version, its facet-specific rationale, the learner's required operation and artifact, and a separate review that attempts the actual task before seeing keys or author rationale. That evidence is currently missing from the formal ledger for all 383. This report supplies an audit trail and identifies repairs; it does not manufacture the missing independent contexts.
