# 07.12 — Fresh checks

Attempt these before opening [answers](check-answers.md).

1. A twenty-minute attempt includes a ten-minute necessary interruption. How many task minutes were available?

2. The restart improves after reducing scope, but it also has eighteen uninterrupted active minutes instead of ten. Is scope reduction isolated as the cause?

3. The table is clearer, but another person's tray becomes crowded and a key's owner is unknown. Should these limits be omitted to show resilience?
