## Changed-case answer

Name the capacity limit and offer 12:15 for ten minutes, asking whether that works. A unilateral “later” is not a return agreement. If the deadline is 10:00, 12:15 is unusable: agree an earlier brief decision, a permitted interim choice, or openly state inability. Do not treat a promised return as completed regulation or repair.
