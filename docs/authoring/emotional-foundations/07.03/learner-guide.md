# 07.03 — The pause between feeling and action

## A pause needs a return route

A pause interrupts a costly reaction while keeping the feeling and underlying issue available. It is not indefinite silence, emotional suppression or a way to make someone else wait for permission. The complete skill is cue, brief action, return and an eventual response that addresses the matter. Immediate safety action must not be delayed by a practice card.

Use fifteen minutes to prepare, two short rehearsals and ten minutes to review the supplied use. NHS anger guidance [S02](../SOURCES.md#S02) supports time to think before reacting. The return promise and messages below are original educational material, not a crisis or treatment protocol. Choose only ordinary nonurgent situations; prayer is optional and no religious or breath practice is required.

## Complete message and return card

At 14:00 fictional Devon receives: “Your room booking note is confusing. Please clarify whether we meet in B or C by 15:00.” The official confirmation in the supplied file says Room C. Devon notices an urge to reply, “Read it properly before criticizing me.” The concern to retain is the genuine room ambiguity, not whether the sender agrees Devon is competent.

The card reads: “Cue: reaching for Send while drafting blame. Action: leave the draft unsent and look around the room for ninety seconds. Return: answer by 14:30, with Room C from the confirmation. Exception: immediate danger or urgent safety duty uses the appropriate response, not this delay.” Looking around may be replaced with comfortable movement, a short private written note, welcome consultation or prayer that fits the person. No breath manipulation is prescribed.

A holding message is: “I will check the confirmation and reply by 14:30.” It tells the other person what to expect without demanding reassurance. The worked eventual response begins: “The confirmation says Room C. My earlier note was unclear; please use C.” The sender's criticism may still sting. Addressing the ambiguity does not require proving the feeling wrong.

The second rehearsal message is: “Your note gives two start times. Which is correct by 16:00?” Its authoritative record says 16:30. Rehearse the same cue–action–return structure with a 15:30 return, not the earlier room answer. A rehearsal is preparation even if no regrettable message is sent during it.

## Interrupt, return, assess the actual reply

1. Write the trigger, cue, unsent reaction, concrete cost and issue that still needs attention. Here an accusation could increase avoidable conflict while leaving the room unknown. Include the safety exception. A brief pause is only suitable if it fits the real deadline and setting.
2. Rehearse both messages using a comfortable action and a feasible return time. Save the first sentence of each factual response before opening the [later packet](later-packet.md). Notice that a ninety-second pause and a thirty-minute return window are different durations; the remaining time may be needed to check information.
3. In the later record, check whether the accusation was withheld, the response returned by the promise and the issue was answered accurately. Retain any failure in those separate checks. “I paused” cannot stand in for “I followed through.” If a deadline will be missed, communicate or use an appropriate alternative as soon as possible rather than disappearing.

## Make the pause available without making it compulsory

For support, keep the card visible, use a prewritten holding note or ask a chosen supporter to help with an ordinary fact check. If a conversation is unsafe, leave safely and seek appropriate support; do not practice staying exposed to danger. If no suitable opportunity occurs, retain rehearsal status.

A harder case has a response due in thirty seconds. A ninety-second action does not fit; use the needed timely action or an already agreed safe alternative. Later transfer can test a different nonurgent trigger, while preserving the distinction between a prevented send, an actual return and a resolved issue. This episode does not establish regulation in emergencies or across relationships.

## Use the result at its proper scale

Not therapy or diagnosis; severe or persistent symptoms require qualified mental-health or medical care.

Fiction and no attempt are legitimate. Subjective ratings, source exercises and completion do not diagnose, establish mastery or score human dignity. Actual situations require appropriate access, consent, authority and support.
