# 07.11 — Fresh checks

Attempt these before opening [answers](check-answers.md).

1. A present meal is useful. Does that make a missed project deadline a good event?

2. A reduced-scope proposal is declined and a revised-date request has no answer. Which future outcome is established?

3. The person stops at the agreed enough-for-now boundary while still disappointed. Must they abandon ambition or pretend to feel joy?
